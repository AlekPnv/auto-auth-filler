Advanced / Troubleshooting

Chrome: Open chrome://extensions, turn on Developer Mode and load this folder as an unpacked extension.

Firefox: Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select manifest.json.

OAuth client: The registered client ID needs this extension's redirect URL added in Google Cloud Console, under APIs and Services, then Credentials. The redirect URL is printed to the browser console the first time sign-in runs.
