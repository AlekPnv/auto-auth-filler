Advanced / Troubleshooting

Chrome: Go to chrome://extensions, enable Developer Mode, load the Auto-Auth-Filler-v3 folder as an unpacked extension.

Firefox: Go to about:debugging#/runtime/this-firefox, load temporary add-on, select manifest.json.

OAuth client: The registered client ID must have the extension's redirect URL added in Google Cloud Console → APIs & Services → Credentials. The redirect URL is shown in the browser console when auth is first triggered.
